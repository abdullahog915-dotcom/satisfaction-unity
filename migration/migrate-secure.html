🔒 Secure Supabase Migration Tool

Server-side migration with secure credentials

✅ Secure Architecture

This tool uses server-side migration endpoints. Your Supabase service key remains secure on the server and is NEVER exposed to the browser.

⚠️ Before Starting

1. Run database migrations in Supabase SQL Editor: supabase/migrations/00_run_all_migrations.sql
2. Create storage buckets: product-images and banner-media
3. Set environment variables in Cloudflare Pages:
  • SUPABASE_URL
  • SUPABASE_SERVICE_KEY
  • MIGRATION_SECRET (generate a random secret)
4. Enter your MIGRATION_SECRET below to authorize this migration

Authorization

This secret authorizes the migration. It must match the MIGRATION_SECRET environment variable in Cloudflare Pages.
